# Readable notebooks

Open the [complete notebook index](../docs/notebook-index.md) for course-ordered
links and lecture-slide page ranges.

- `course/`: converted course notebooks in original section/lesson order.
- `db-connect/`: reading copy of the Databricks Connect reporting notebook.
- `bundle-demo/`: reading copy of the bundle demonstration notebook.

Read notebooks without running them. Python, SQL, Databricks magics, cloud
references, and saved results retain their original context. Unsupported
Databricks commands are displayed as labelled source rather than made to appear
locally runnable.

The separate Jobs archive duplicates three lessons in the main archive; these
are indexed as aliases rather than duplicate study copies.

The reading copies use compact saved result previews, not full raw input dumps.
Complete supplied inputs stay in `data/`; original materials and full archived
payloads remain separate from the reading flow. Shortened previews never imply
that rows were re-executed or that missing cloud state was recreated.

See [reading and presentation policy](../docs/notebook-reading.md) for preview
limits, full-payload preservation, and viewer compatibility.
